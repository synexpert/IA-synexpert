# IA-synexpert

Projet d’assistant documentaire du **CABINET SYN EXPERT**, entre Clermont-Ferrand et Casablanca.

## Objectif métier

Permettre à un collaborateur de poser une question sur une procédure du cabinet, de retrouver les passages pertinents et de vérifier la réponse dans le document d’origine.

## Architecture prévue

- **Interface dédiée** sur `ia.synexpert.fr` pour poser les questions et consulter les sources.
- **Recherche documentaire (RAG)** pour sélectionner les extraits utiles avant de générer une réponse.
- **Intégration prévue avec Odoo 20**, avec un hébergement distinct pour l’assistant.

## État du projet

Ce dépôt présente le périmètre du projet. Le premier cas d’usage prévu est la consultation de procédures internes, avec citation du document de référence.
